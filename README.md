# Jarvis Autonomous Command Center

**Jarvis Command Center** is a cyberpunk-themed executive HUD orchestrating a multi-agent AI neural mesh, featuring ultra-low latency voice synthesis via ElevenLabs and real-time financial telemetry.

## Features
- **Neural Mesh Architecture**: Coordinatess specialized autonomous subagents in parallel.
- **Voice Synthesis HUD**: Integrated with ElevenLabs for neural voice interaction with an animated audio visualizer waveform.
- **Live Token Ledger**: Real-time tracking of OpenAI/Anthropic API costs and token spend across tasks.

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- WebSockets
- ElevenLabs API
